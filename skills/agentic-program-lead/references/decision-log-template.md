# Decision Log Template

Use for material product/program decisions that constrain future work but do not justify a full ADR.

```markdown
## YYYY-MM-DD — <Decision title>

**Decision:**
<What was decided.>

**Rationale:**
<Why this option was selected.>

**Consequences:**
- <Important consequence>
- <Important trade-off>

**Revisit:**
<Trigger/date/milestone, or "No planned revisit".>

**Related:**
<PRD section / issue / ADR / evidence links>
```

Keep entries concise. The log is an index of settled choices, not meeting minutes.
